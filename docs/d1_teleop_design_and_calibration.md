# D1 双臂遥操方案与现场标定记录

本文记录 2026-09-03 已确认的硬件条件、遥操设计、初始安全工作区及下一轮现场标定。
本阶段不接 cambot 实体硬件，Quest 3 继续使用 WebXR。

## 1. 已确认条件

- `left`：D1 670 mm 带夹爪，`192.168.123.100`，电脑端 `enp5s0` / `192.168.123.97`。
- `right`：D1 670 mm 带夹爪，`192.168.123.99`，电脑端 `enx00e04c681b82` / `192.168.123.98`。
- 两个底座转轴中心相距约 0.26 m，按人手方式镜像安装；左右接线口分别朝左右外侧。
- D1 控制周期采用 10 Hz。
- 当前调试硬限幅暂定：关节单周期 30°、夹爪单周期 10 单位；30°只作为异常目标硬边界，
  不代表正常运动应在 0.1 s 内跳变 30°。

## 2. 确定的遥操交互方案

采用“机械臂 Home + 手柄现场对齐 + 明确启动”的方式，正常遥操不要求持续按侧握键：

1. 上电、使能后保持当前位置。
2. 操作者确认工作区安全，双臂沿已验证的安全航点低速进入各自 Home。
3. 操作者把左右手柄置于舒适、对称的 Home 姿态。
4. 长按 A（左手柄为 X）约 0.8 秒完成对齐：同时记录当前手柄位姿和对应机械臂 TCP 位姿。
5. 进入遥操；食指扳机控制对应夹爪。
6. B 立即暂停并保持目标。暂停或追踪丢失后，必须重新摆好手柄并长按 A 对齐，禁止自动恢复。

实现同时保留 `deadman` 方式用于对照测试：`--engagement-mode deadman` 需要持续按侧握键；
上述 Home 连续方式使用 `--engagement-mode home`。

Quest 按键不是安全等级急停，现场仍需可触及的实体急停。侧握键可不用于正常操作；若后续需要临时
重置手柄活动范围，可再评估将其作为可选 clutch。

Home 必须保存左右臂各自的六关节角，不能把 `zero` 当作 Home，也不能未经验证直接令另一臂取镜像负值。
从任意姿态回 Home 应使用安全航点，并在反馈误差达到阈值后才进入手柄对齐阶段。

## 3. 初始工作区

统一俯视坐标系定义为：`+X` 向右、`+Y` 向公共工作区前方、`+Z` 向上；底座中心分别为
`left=(-0.13, 0, 0)`、`right=(+0.13, 0, 0)`。

基于 670 URDF 的无碰撞约束随机正运动学估算，单臂最大水平半径约 0.63 m。由于两圆在 0.26 m
底座间距下高度重叠，理论最大包络不能直接作为安全区。第一版采用：

- 每臂水平半径 `0.20–0.55 m`；
- 左臂仅开放左外侧至公共前方的 90°扇区；
- 右臂仅开放右外侧至公共前方的 90°扇区；
- 初始高度建议相对底座安装面 `0.12–0.55 m`，最终按桌面和安装高度修订；
- 暂不允许 TCP 穿越中央分界线；中央双臂协作区留到碰撞约束完成后开放。

每臂平面扇区约 0.206 m²，合计约 0.412 m²；整体外包络约 1.36 m 宽、0.55 m 前向深。
这些数值是首轮安全边界，不是机械极限。

## 4. 单臂隔离原则

现场标定严格一次只接通、上电、使能和控制一只臂。所有相关入口支持
`--arm left`、`--arm right` 或 `--arm both`。选择单臂时：

- 不检查未选择臂的网卡和路由；
- 不启动未选择臂的 DDS bridge；
- 不连接未选择臂的 TCP 客户端；
- VR 只读取与该臂同侧的 Quest 手柄；
- 退出时只对所选臂执行卸力/断电。

左臂测试初始化：

```bash
sudo ./scripts/setup_d1_network.sh --arm left
./scripts/test_dual_d1.sh status --arm left --watch --seconds 5
./scripts/test_dual_d1.sh action power-on --arm left --yes
./scripts/test_dual_d1.sh action enable --arm left --yes
```

右臂测试时把所有 `left` 改为 `right`。测试结束只处理当前臂：

```bash
./scripts/test_dual_d1.sh action disable --arm left --yes
./scripts/test_dual_d1.sh action power-off --arm left --yes
```

单臂 VR 入口：

```bash
./scripts/start_vr_d1_teleop.sh --yes --arm left --control-mode position
# 或
./scripts/start_vr_d1_teleop.sh --yes --arm right --control-mode position
```

## 5. 下一轮现场标定顺序

应按以下顺序执行，并先完整完成左臂，再断开/断电左臂并测试右臂。

### 5.1 夹爪方向和范围

以夹爪当前反馈为基准，用 `--joint 6 --delta 5` 小步测试：

```bash
./scripts/test_dual_d1.sh jog --arm left --joint 6 --delta 5 --hold-seconds 2 --yes
./scripts/test_dual_d1.sh jog --arm left --joint 6 --delta -5 --hold-seconds 2 --yes
```

记录每臂：正增量开/合方向、完全打开反馈、完全闭合反馈，以及是否出现停转/异响。
不要直接连续走到端点。

### 5.2 平移坐标方向

使用 `--control-mode position`，一次只沿手柄一个轴移动约 5 cm，分别测试上/下、前/后、左/右。
该模式把末端姿态锁定在侧握键接合瞬间，避免平移测试混入手柄旋转。
记录每个 Quest 轴对应的机械臂物理方向及正负号。左右臂必须分别标定，不从镜像安装关系直接猜符号。

### 5.3 TCP 和旋转中心

使用 `--control-mode orientation`。在夹爪两指中点固定轻质标记，在非伸直、非折叠姿态下保持
位置目标，仅改变单个姿态轴约 ±5°。
若夹爪中心沿圆弧移动，说明 TCP 存在偏置；中心漂移小于约 5 mm 可作为首轮通过标准。
若出现突然换肘型或大幅跳动，应归类为 IK 分支/奇异点问题。

已修正原实现误把一侧夹指 `Joint7_1` 当作末端的问题。当前在 `Link6` 后追加显式、对称的
`gripper_center_tcp`：初值由 URDF 两根手指安装原点的中点得到，为
`[-5.62, 0, 70.6] mm`。该值消除了约 29.6 mm 的单指横向偏置，但沿工具轴的实际夹取点仍需
用本测试确认；测得稳定偏差后再回填最终 TCP。
